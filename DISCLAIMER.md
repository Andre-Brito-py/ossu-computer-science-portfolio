# Academic Integrity Disclaimer

This repository serves as a personal portfolio to showcase my completion of the [Open Source Society University (OSSU) Computer Science Curriculum](https://github.com/ossu/computer-science).

## Compliance with Course Policies

In accordance with the Academic Integrity policies and the Code of Conduct of the respective universities and platforms (e.g., Coursera, edX) that provide these courses:

1. **No Graded Solutions:** This repository does **NOT** contain solutions to graded quizzes, exams, or proprietary assignments.
2. **Authorized Sharing Only:** The code, projects, and notes shared in this repository are exclusively those that are explicitly allowed to be shared publicly by the course instructors.
3. **Personal Work:** Any code or notes provided here represent my own original work, created for learning and portfolio purposes.

## Note to Current Students

If you are currently enrolled in any of these courses, I strongly encourage you to solve the problems and complete the projects on your own. Looking at others' solutions will deprive you of the learning process that is essential to mastering Computer Science.

*Please respect the honor code of your courses!*
